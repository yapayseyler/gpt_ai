# Codex Calculator

Bu proje, Codex gibi yapay zeka sistemleri ile kullanılmak üzere hazırlanmış basit bir Python hesap makinesi modülüdür.

## Özellikler

- Toplama
- Çıkarma
- Çarpma
- Bölme (sıfıra bölme kontrolü ile)

## Kullanım

```python
import calculator

print(calculator.add(2, 3))  # 5
print(calculator.divide(10, 2))  # 5.0
